## 0. 本版相对 v1 的变化

v2 在保持 v1 已定方向（门禁、Key 哈希、通用上游插件、`generations/assets`）的前提下，吸收参考项目 **YesNAI_Studio_RP（星彩绘图台）** 的「多账号云端中转 + 持久画廊 + 对外网关 + 自动签到」能力，并按本项目决策改造。主要变化：

1. 新增 **账号池（Account Pool）**：多账号、凭据加密、JWT 自动重登、余额刷新、轮询/余额优先选择、账号级冷却。
2. 新增/强化 **对外网关**：`mode = passthrough | restricted`、完整 `policy` 字段集、restricted 参数改写、失败转移分级、请求/尝试留痕、响应头回传。
3. 新增 **D1 原子预占与并发租约**写法（无事务下用 `INSERT...ON CONFLICT...WHERE` 与 `INSERT...SELECT...WHERE COUNT<max`）。
4. 新增 **计量与日志**：`request_logs`、`request_attempts`、`daily_usage`（并入 `usage_counters` 体系）。
5. 明确 **对外网关密钥（Bearer，哈希存储）与面板会话 Cookie 双通道并存**及鉴权矩阵。
6. 数据模型升级到 **V2**（通用化合并蓝本表）。
7. 明确 **上游默认协议为 `nai-compatible`（默认上游 `nai.rinko.ai` 多账号池）**，兼容 `openai-compatible` 与模板适配器。
8. 更新实现顺序，补充安全章节。
9. 新增 **自动签到**能力（工作日/周末多时间槽 × IANA 时区、升序补签、失败退避、终态处理），详见 [05-自动签到.md](05-自动签到.md)。

## 0.1 v1.1.0 已实现并上线（相对 v2 设计稿）

v2 设计已落地，并在实现中新增/调整如下能力（以实际代码为准）：

1. **门禁改造**：owner 仍用 secret `OWNER_PASSWORD`；朋友分享密码移入 D1 表 `share_passwords`（可增删改、`salt+sha256` 哈希、`quota_bytes` 默认 500MB、`enabled`）；会话 payload 增加 `sid`（owner=`owner`，friend=分享密码 id）；**旧 `FRIEND_PASSWORD` 已忽略**。
2. **画廊按 sid 隔离**：friend 仅见/操作自己 sid 的图；owner 默认全部、可按 sid 筛选；新增 `GET /api/gallery/overview`（owner）与 `GET /api/gallery/:id/meta`（图片信息，含模型/采样器/步数/种子/提示词等，兼容旧 `negative_prompt` 格式）。
3. **字节配额**：每分享密码 `quota_bytes`（默认 500MB），按 `assets.size_bytes`（原图+缩略图）求和；friend 超限时 `POST /api/generate` 返回 403 `quota_exceeded` 且不调上游；owner 不限。
4. **账号池增强**：批量获取 Token（`POST /api/accounts/provision_all`）与批量删除（`POST /api/accounts/batch_delete`）；生图 Token 命名 `DW-YYMMDDHHmm`。
5. **账号限额**：默认每账号 **10 分钟 20 张**，配置在上游 `capabilities_json.account_limit`；**仅成功计入**；**全局统一计数**（工作台与网关共享，表 `account_usage`）；达限跳过、全达限兜底。
6. **重试/失败转移**：单账号失败（含超时/连接）换号，最多轮遍同上游所有账号；**401 只重登（`refreshJwt`），不重建 token**，重登成功不计失败；全池冷却时兜底选最早到期账号。
7. **工作台与 API 独立选号**：`POST /api/generate` 可指定 `upstream_id`/`account_mode(auto|balance|fixed)`/`account_id`；工作台用 `selectionScope='workspace'` 独立游标，与网关互不干扰；新增 `GET/PATCH /api/generate/options`（上游精简列表 + 模型/采样器/尺寸/动作选项 + 账号 + 模式）。
8. **配方与画师串**：D1 表 `presets`（`kind=recipe|artist`），按 sid 分区；friend 可管理自己的；owner 可只读查看他人（`GET /api/presets?sid=`、`GET /api/presets/overview`）；**内置 6 套画师串**（见 `apps/worker/src/presets/builtinArtists.ts`）。画师串由前端拼接到正向提示词最前。
9. **生成日志与个人资料**：`/api/logs`（owner，分类 workbench/gateway）、`/api/profile`（owner，只读身份/站点信息 + 可编辑昵称/头像色/偏好）；表 `app_profile`。
10. **静态资源门禁**：`run_worker_first` 仅对 API/网关/SPA 导航路径生效，静态子资源由 Assets 直出（省额度）；`staticGate` 未登录导航 302 `/login`。
11. **前端查询缓存**：React Query `staleTime`（画廊/预设 30s、配置类 5min）、`retry:0`；图片长缓存 immutable。
12. **部署与工具**：自定义域名 `dw.646677.xyz`；`APP_VERSION` 由 wrangler `[vars]` 注入；无代理/走代理 7893 的部署与 git 包装脚本 `scripts/`。

## 1. 项目目标

面向个人、自部署在 **Cloudflare Workers** 的 **NovelAI 生图聚合工作台**：
- 打开项目即为**门禁**（所有者密码 / 朋友分享密码），进入后在**工作台生图**、**查看画廊**。
- 可作为**上游聚合网关**：对外接受 API 请求，改写后透传到可配置的上游，返回图片。
- 支持**分发 API Key** 给别人使用。

## 2. 功能需求

1. **工作台生图 + 画廊**：门禁后进入创作台生图，并浏览作品；画廊**按 sid 隔离**（friend 仅见自己，owner 可见全部/按 sid 筛选）。
2. **上游可变**：可接入的生图上游能够运行时增删改启停，不写死。**默认上游为 `nai.rinko.ai` 多账号池**。
3. **账号池**：托管多个上游账号，自动重登、刷新余额、按策略选号、失败冷却与转移；支持批量获取 Token / 批量删除；账号限额（默认 10 分钟 20 张）全局计数。
4. **API 透传与改写**：接受外部 API 请求，改写后透传上游，返回图片；支持格式映射、提示词改写、内容策略、请求控制与失败转移。
5. **分发 API Key**：签发受控的 key 供他人调用（仅存哈希，带策略）。
6. **计量与日志**：按 key/账号记录用量、成本、耗时与每次尝试明细；面板提供生成日志（工作台/网关分类）。
7. **分享密码与配额**：owner 可增删改朋友分享密码（D1 `share_passwords`），每个分享密码带字节配额；friend 超出配额时拒绝生图。
8. **配方与画师串**：用户可保存/复用参数配方（`recipe`）与提示词片段（画师串，`artist`）；内置 6 套画师串；均按 sid 分区。
9. **自动签到**：按上游分组展示账号、支持单账号手动签到与全量测试，Cron 定时执行。
10. **个人资料**：owner 查看身份/站点信息并维护昵称、头像色与偏好。
