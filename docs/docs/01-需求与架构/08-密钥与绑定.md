## 9. 新增 secret / 绑定需求

### 9.1 密钥职责（两把 secret）

| 名称 | 职责 | 算法 |
| --- | --- | --- |
| `SESSION_SECRET` | 会话 Cookie 的 HMAC 签名 | HMAC-SHA256（**仅签名，不加密**） |
| `ENCRYPTION_KEY` | **唯一的对称数据加密主密钥** | 作为 HKDF 主密钥，派生用途子密钥 |

**HKDF 派生用法**（同一 `ENCRYPTION_KEY`，按 `info` 分离用途）：

| 子密钥 | 派生方式 | 用途 |
| --- | --- | --- |
| 凭据加密子密钥 | `HKDF(ENCRYPTION_KEY, info="credentials")` | 账号池凭据 `accounts.credential_enc` 的 AES-GCM 加密 |
| 上游配置加密子密钥 | `HKDF(ENCRYPTION_KEY, info="upstreams")` | `upstreams.auth_enc` 的 AES-GCM 加密 |

> `SESSION_SECRET` 必须独立：它只做签名，泄露后果与数据加密密钥不同，**不与 `ENCRYPTION_KEY` 合并**。账号凭据加密不再使用独立的凭据加密 secret，其职责由 `ENCRYPTION_KEY` 经 HKDF `info="credentials"` 派生的子密钥承担。

### 9.2 secret / 绑定清单

| 类型 | 名称 | 用途 | 说明 |
| --- | --- | --- | --- |
| Secret（**新增**） | `ENCRYPTION_KEY` | **唯一对称数据加密主密钥**（HKDF 派生用途子密钥） | 派生 `info="credentials"`（账号凭据）/ `info="upstreams"`（上游配置） |
| Secret（已有） | `OWNER_PASSWORD` | owner 门禁密码 | 仍在使用；不落库 |
| Secret（**已忽略**） | `FRIEND_PASSWORD` | ~~朋友门禁密码~~ | **v1.1.0 起不再读取**，朋友分享密码改由 D1 `share_passwords` 管理；此 secret 可移除 |
| Secret（已有） | `SESSION_SECRET` | 会话 HMAC 签名 | 仅签名不加密，独立于 `ENCRYPTION_KEY` |
| Var（`[vars]`） | `APP_VERSION` | 版本号，注入 `GET /api/profile` 站点信息 | 当前 `1.1.0` |
| Var（`[vars]`） | `APP_ENV` | 运行环境标识 | `production` / `development`（影响 Secure Cookie） |
| Var（可选） | `DEFAULT_SHARE_QUOTA_BYTES` | 分享密码默认配额覆盖 | 缺省 500MB |
| 绑定 | `DB`（D1） | 元数据/计数/日志 | 含 `share_passwords`/`presets`/`account_usage`/`app_profile`/`checkin_*` |
| 绑定 | `BUCKET`（R2） | 图片对象（`img/`、`thumb/`） | 代码与 wrangler 绑定名为 `BUCKET`（非 `R2`） |
| 绑定 | `ASSETS` | 静态资源 | 需配合门禁，见 [04-接口与鉴权.md](04-接口与鉴权.md) 的 6.3 |
| Route | 自定义域名 `dw.646677.xyz` | 生产入口 | `custom_domain = true` |
| Trigger | Cron `*/5 * * * *` | 余额刷新、冷却回收、自动签到（见 [05-自动签到.md](05-自动签到.md)） | 本版本启用 |

> **敏感值管理**：`OWNER_PASSWORD`、`SESSION_SECRET`、`ENCRYPTION_KEY` 经 `wrangler secret put` / `.dev.vars`（已忽略）管理，**不写入 `wrangler.toml`**；朋友分享密码由面板写入 D1 `share_passwords`（仅哈希）。`APP_VERSION`/`APP_ENV` 为非敏感 `[vars]`。
> **部署工具**：`scripts/` 提供无代理与走代理（7893）的 wrangler / git 包装脚本，便于本地部署与提交。
