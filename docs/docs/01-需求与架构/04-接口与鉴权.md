## 6. 接口草案

### 6.1 内部面板 API（`/api/*`，Cookie 会话）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 密码门禁：owner 比对 `OWNER_PASSWORD`，否则遍历启用的 `share_passwords` 校验；成功回 `{role, sid}` |
| POST | `/api/auth/logout` | 登出 |
| GET | `/api/auth/me` | 当前身份 `{role, sid}` |
| POST | `/api/generate` | 工作台生图（走统一管线）；可传 `upstream_id`/`account_mode`/`account_id`；friend 先做配额校验 |
| GET | `/api/generate/options` | 工作台上游精简列表 + 模型/采样器/噪声/尺寸/动作选项 + 账号（owner）+ 模式 + 当前设置 |
| PATCH | `/api/generate/options` | 更新工作台设置（`upstream_id`/`account_mode`/`account_id`）；指定 `account_id` 仅 owner |
| GET | `/api/gallery` | 本地作品列表（owner 可 `?sid=` 过滤） |
| GET | `/api/gallery/overview` | 画廊按 sid 总览（owner）：各 sid 用量/张数 |
| GET | `/api/gallery/{id}/meta` | 单图信息（模型/采样器/步数/种子/提示词等，兼容旧格式） |
| GET/DELETE | `/api/gallery/{id}`、`POST /api/gallery/clear` | 画廊删除/清空（按 sid 权限） |
| POST | `/api/gallery/{id}/thumb` | 上传缩略图并累加 `size_bytes` |
| GET | `/api/gallery/i/{id}` | 取图（`?t=img\|thumb`，长缓存，按 sid 校验） |
| CRUD | `/api/upstreams` | 上游管理（owner） |
| CRUD | `/api/accounts` | 账号池管理（owner）；凭据不回传；含 `POST /batch`、`/provision_all`、`/batch_delete`、`/refresh_gems`、`/:id/balance`、`/:id/provision_token`、`/:id/test` |
| CRUD | `/api/keys` | API Key 签发与管理（owner） |
| CRUD | `/api/rewrite-rules` | 改写规则管理（owner） |
| CRUD | `/api/share-passwords` | 分享密码管理（owner）；`GET` 附带各 sid 用量；删密码不删其画廊 |
| GET/POST/PATCH/DELETE | `/api/presets` | 配方/画师串（`?kind=recipe\|artist`，owner 可 `?sid=` 只读查看）；`GET /api/presets/overview`（owner） |
| GET | `/api/logs`、`/api/logs/{requestId}/attempts` | 生成日志（owner，`?source=workbench\|gateway`）与尝试明细 |
| GET/PATCH | `/api/profile` | 个人资料（owner）：只读身份/站点信息 + 可编辑昵称/头像色/偏好 |
| GET/PATCH | `/api/checkin/settings` | 签到时刻表读取/更新（owner），见 [05-自动签到.md](05-自动签到.md) |
| POST | `/api/checkin/test` | 手动全账号签到（owner），见 [05-自动签到.md](05-自动签到.md)；另有 `POST /api/accounts/{id}/test` 单账号 |
| GET | `/api/health` | 健康检查 |

> 写操作（POST/PATCH/PUT/DELETE）除会话校验外，叠加 **Origin 校验** 防 CSRF（`Origin` 缺失时放行，兼容 curl）。

### 6.2 对外网关 API（`/v1/*`、`/generate`，Bearer key 哈希校验）

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/v1/nai/generate-image` | `Bearer <key>` | NAI 原生兼容，支持完整 policy |
| POST | `/v1/images/generations` | `Bearer <key>` | OpenAI 图像兼容（body 归一化为 NAI） |
| GET | `/generate` | `Bearer <key>` 或 `?token=<key>`（下游兼容） | 返回 PNG；供魔改版直链 |
| GET | `/v1/models` | `Bearer <key>` | 归一化模型列表 |

> **与下游魔改版的兼容点**：魔改版将 token 放 query（`/generate?tag=...&token=...`），因此 `GET /generate` 允许 `?token=`；无论载体如何，一律按 `api_keys.key_hash` 校验，**不存明文**。

### 6.3 鉴权矩阵

| 通道 | 载体 | 覆盖范围 | 校验方式 | 优先级/回落 |
| --- | --- | --- | --- | --- |
| 面板 API | `Cookie: <session>`（HMAC 签名 HttpOnly） | `/api/*`（除登录等公开项） | 会话签名 + 角色（owner/friend）+ **`sid` 分区** | 主通道；面板内不认 Bearer |
| 分享密码来源 | D1 `share_passwords`（`salt+sha256`，`enabled=1`） | 登录 `POST /api/auth/login` | 遍历启用行、逐行加盐哈希后常量时间比较；命中回该行 `id` 作 `sid`、`role` | **owner 优先**：先比对 secret `OWNER_PASSWORD`，未命中再查分享密码；旧 `FRIEND_PASSWORD` 不再参与 |
| 对外网关 API | `Authorization: Bearer <key>` | `/v1/*`、`/generate` | `key_hash = SHA-256(key)` 查 `api_keys`，读 `mode`/`policy` | 主通道；`GET /generate` 可回落 `?token=` |
| 上游请求 | 账号 `credential_enc`（AES-GCM，密钥由 `ENCRYPTION_KEY` 经 HKDF `info="credentials"` 派生）与 `upstreams.auth_enc`（HKDF `info="upstreams"` 派生） | Worker → 上游 | 出站适配器解密并注入（如 `Authorization: Bearer`） | 仅服务端可见，绝不回传 |
| 静态资源 | `Cookie: <session>` | SPA 资源（`ASSETS`） | **需要门禁**：`run_worker_first` 仅覆盖 `/api/*`、`/v1/*`、`/generate`、`/`、`/console*`、`/gallery*`、`/login`；静态子资源（`/assets/*`、`*.js/*.css/*.png`、favicon）由 Assets 直出 | Worker 先行鉴权，未登录 HTML 导航 302 `/login` |

**会话载荷**：`{ role, sid, iat, exp }`，TTL 7 天；`sessionMiddleware` 解析后置入 `c.set("role")`/`c.set("sid")`。**`sid` 是画廊/预设分区的唯一键**。

**静态资源门禁实现提示**：`staticGate` 对 API/网关前缀回 404、对带扩展名的资源与 `/assets/*` 直出、对未登录的 HTML 导航 302 `/login`，其余回落到 `/index.html`。SPA 需保证 `/login` 及登录所需最小资源无需会话即可访问，否则会重定向循环。`run_worker_first` 采用 glob 白名单数组（见 `apps/worker/wrangler.toml`），静态子资源不唤醒 Worker 以节省额度。
