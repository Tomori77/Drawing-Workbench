# 01 · 需求与架构（索引）

> 状态：v1.1.0 已实现并上线，本文档同步现状。
> 版本：**v1.1.0** ｜ 更新日期：**2026-10-02** ｜ 上一版：v2（设计稿）。
> 本文是总索引/总览。详细内容已拆分为 `01-需求与架构/` 下的子文档，见下方阅读顺序与清单。实现变更时同步更新。

面向个人、自部署在 Cloudflare Workers 的 **NovelAI 生图聚合工作台**：门禁进入后在工作台生图并浏览画廊，同时可作为上游聚合网关对外分发受控 API Key。

> **v1.1.0 现状**：v2 设计已基本落地。门禁改为 owner secret + **D1 `share_passwords` 朋友分享密码**；画廊按 `sid` 隔离并带字节配额；账号池新增**账号限额/重试/401 重登/全池兜底**；工作台与网关**独立选号**；新增**配方/画师串、生成日志、个人资料**页面与接口；静态资源门禁改为 `run_worker_first` 白名单。已完成项见 [06-实现顺序.md](01-需求与架构/06-实现顺序.md)。

## 本版关键决策速览

| 主题 | 决策（一句话） |
| --- | --- |
| 门禁 | **保留本项目实现**：owner 用 secret `OWNER_PASSWORD`；friend 分享密码实体化入 D1 `share_passwords`（salt+sha256、可增删改）；会话带 `sid`（owner=`owner`，friend=分享密码 id）。**旧 `FRIEND_PASSWORD` 已忽略**。 |
| Key 存储 | **仅哈希**：对外 API Key 与面板 key 一律只存 SHA-256 哈希，不存明文；分享密码亦仅存 `salt+sha256` 哈希。 |
| 画廊隔离 | **按 `sid` 分区**：friend 仅见自己 sid 的图；owner 默认全部并可按 sid 筛选；`GET /api/gallery/overview` 给 owner 总览。 |
| 配额 | **每分享密码 `quota_bytes`（默认 500MB）**：按 `assets.size_bytes`（原图+缩略图）求和；friend 超限 `POST /api/generate` 返回 403 `quota_exceeded` 且不调上游；owner 不限。 |
| 账号限额 | **默认每账号 10 分钟 20 张**（`capabilities_json.account_limit`）；**仅成功计入**、**工作台与网关全局统一计数**（表 `account_usage`）；达限跳过，全达限兜底。 |
| 重试/失败转移 | **单账号失败换号，最多轮遍同上游全部账号**；**401 只重登（`refreshJwt`）不重建 token**，重登成功不计失败；全池冷却时兜底选最早到期账号。 |
| 工作台选号 | **独立于网关**：`POST /api/generate` 可指定 `upstream_id`/`account_mode(auto\|balance\|fixed)`/`account_id`；工作台用 `selectionScope='workspace'` 独立游标；`GET/PATCH /api/generate/options` 提供动态选项。 |
| 配方/画师串 | **D1 表 `presets`（`kind=recipe\|artist`）按 sid 分区**；friend 管自己、owner 只读查看他人；内置 **6 套画师串**；画师串由前端拼接到正向提示词最前。中文转 Tag 未实现（占位）。 |
| 静态资源门禁 | **`run_worker_first` 仅覆盖 API/网关/SPA 导航路径**，静态子资源由 Assets 直出（省额度）；`staticGate` 未登录导航 302 `/login`。 |
| 上游 | **插件化、默认 NAI**：默认协议 `nai-compatible`（`nai.rinko.ai` 多账号池），兼容 `openai-compatible` 与模板适配器。 |
| 数据模型 | **通用化**：沿用本项目 `generations`/`assets`，不照抄蓝本强绑 NAI 的 `gallery` 列。 |
| 时区 | **日界固定 Asia/Shanghai**：`daily_usage` 按北京/上海时间划分每日。 |
| 静态资源 | **需要门禁**：未登录访问受保护页面引导至 `/login`，登录所需最小资源放行。 |
| 画廊删除 | **不软删除**：直接删 R2 两对象 + D1 行，去重与防重生交由下游。 |
| 结果缓存 | **不做服务端结果缓存**：网关响应一律 `Cache-Control: no-store`，每次生图回源上游；R2 仅存画廊 `img/`、`thumb/` 对象。 |
| 密钥 | **单一加密主密钥 `ENCRYPTION_KEY` + HKDF 派生**（`info="credentials"` 账号凭据、`info="upstreams"` 上游认证）；`SESSION_SECRET` 独立，仅做会话 HMAC 签名。 |
| 账号策略 | **默认 `round_robin`（轮询）**，候选含 `round_robin` / `balance_first` / `fixed`（+ `least_used` 扩展位）；冷却是否启用、失败次数阈值与时长**由 owner 运行时配置**。 |
| 自动签到 | **纳入本版本**：Cron `*/5 * * * *`、工作日/周末多时间槽、时区固定 `Asia/Shanghai`、升序补签、失败退避 30 分钟、终态绝不绕过。 |
