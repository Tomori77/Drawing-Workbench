## 本版关键决策速览

| 主题 | 决策（一句话） |
| --- | --- |
| 门禁 | **保留本项目实现**：owner/friend 双密码 + HMAC 签名 HttpOnly Cookie 会话，不采用蓝本单一 `APP_ACCESS_KEY`。 |
| Key 存储 | **仅哈希**：对外 API Key 与面板 key 一律只存 SHA-256 哈希，不存明文。 |
| 上游 | **插件化、默认 NAI**：默认协议 `nai-compatible`（`nai.rinko.ai` 多账号池），兼容 `openai-compatible` 与模板适配器。 |
| 数据模型 | **通用化**：沿用本项目 `generations`/`assets`，不照抄蓝本强绑 NAI 的 `gallery` 列。 |
| 时区 | **日界固定 Asia/Shanghai**：`daily_usage` 按北京/上海时间划分每日。 |
| 静态资源 | **需要门禁**：未登录访问受保护页面引导至 `/login`，登录所需最小资源放行。 |
| 画廊删除 | **不软删除**：直接删 R2 两对象 + D1 行，去重与防重生交由下游。 |
| 结果缓存 | **不做服务端结果缓存**：网关响应一律 `Cache-Control: no-store`，每次生图回源上游；R2 仅存画廊 `img/`、`thumb/` 对象。 |
| 密钥 | **单一加密主密钥 `ENCRYPTION_KEY` + HKDF 派生**（`info="credentials"` 账号凭据、`info="upstreams"` 上游认证）；`SESSION_SECRET` 独立，仅做会话 HMAC 签名。 |
| 账号策略 | **默认 `round_robin`（轮询）**，候选含 `round_robin` / `balance_first` / `fixed`（+ `least_used` 扩展位）；冷却是否启用、失败次数阈值与时长**由 owner 运行时配置**。 |
| 自动签到 | **纳入本版本**：Cron `*/5 * * * *`、工作日/周末多时间槽、时区固定 `Asia/Shanghai`、升序补签、失败退避 30 分钟、终态绝不绕过。 |
