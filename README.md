# Drawing Workbench · 绘图工作台

一个面向个人、自部署在 **Cloudflare Workers** 上的 **NovelAI 生图聚合工作台**。集「门禁 → 生图 → 画廊 → 对外分发」于一体：所有者与朋友用不同密码进入各自独立的创作空间，同时可以把工作台当作受控的上游聚合网关，对外分发 API Key。

> 当前版本：**v1.1.0**

---

## 它能做什么

- **密码门禁**：所有者密码（全权限）与「朋友分享密码」两种入口。分享密码可随时增删改、启停、独立设限。
- **工作台生图**：可选的生图上游、动态的模型/采样器/尺寸选项，支持配方（整套参数快照）与画师串，一键复现历史作品的参数。
- **个人画廊**：生成的作品自动入库（对象存储 + 元数据），支持浏览、放大、右键查看图片信息、下载与删除。
- **对外聚合网关**：以统一的密钥对外提供多格式生图接口，支持配额、限模型、限并发、参数治理与失败转移。
- **自动签到**：按时刻表自动为账号池领取每日额度，失败可退避重试，遇到人机验证绝不绕过。
- **多账号中转**：一个入口托管多个上游账号，凭据加密存储、自动续期、余额刷新、按策略选号。
- **管理后台**：上游、账号池、分享密码、API Key、配方、生成日志、个人资料等一站管理。

---

## 设计理念

- **门禁 + 分区**：每个入口对应一套独立的画廊与预设，彼此不可见；所有者拥有总览视角。
- **可插拔上游**：默认对接 NAI 兼容上游，同时兼容 OpenAI 风格与自定义模板，配置驱动、运行时可变。
- **统一管线**：工作台与对外 API 共用同一条「归一化 → 改写 → 选上游 → 透传 → 响应还原」链路。
- **默认安全**：密钥只存哈希、账号凭据加密落库且永不回传、写操作做同源校验、静态资源默认需要门禁。
- **成本可控**：出图前可估价、失败全额退款逻辑、按账号限额、静态资源与图片长缓存以节省用量。

---

## 适用场景

- 想给自己和家人朋友提供一个稳定的 NovelAI 生图入口，又不希望密码与额度被滥用。
- 想把多个上游账号聚合成一个入口，统一管理额度与计费。
- 想对外提供受控的生图 API，按密钥分发、限额、限模型。

---

## 技术栈

- 前端：Vite + React + TypeScript，Tailwind CSS，Radix UI，TanStack Query，React Router。
- 后端：Cloudflare Workers + Hono（TypeScript）。
- 存储：Cloudflare D1（元数据、配置、计量）与 R2（图片对象）。
- 定时任务：Cloudflare Cron Triggers。
- 工具链：pnpm workspace（monorepo）、Wrangler。

## 快速开始

前置：Node.js、pnpm、一个 Cloudflare 账号（含 Workers / D1 / R2）。

1. **安装依赖**：在仓库根目录执行 `pnpm install`。
2. **创建资源**：在 Cloudflare 创建 D1 数据库与 R2 存储桶，并把绑定信息填入 Worker 配置。
3. **配置密钥**：通过 Wrangler 写入所需的环境密钥（访问密码、会话签名密钥、数据加密密钥等），**不要**写入代码或提交到仓库。
4. **初始化数据库**：应用数据库迁移，创建所需数据表。
5. **本地开发**：同时启动前端与 Worker，浏览器访问本地地址，用所有者密码进入。
6. **部署上线**：构建并发布 Worker；如需自定义域名，在配置中声明后重新部署。

> 具体命令与绑定清单见仓库内的项目手册与设计文档。

## 使用流程

1. 打开站点，用**所有者密码**进入控制台。
2. 在「上游」中确认默认上游，在「账号池」中批量添加账号并一键获取生图凭证（也可批量删除）。
3. 在「创作台」选择上游与账号使用方式，填写提示词（可套用配方与画师串）后生成；结果自动进入画廊。
4. 在「分享密码」中创建朋友入口，为每个入口设置配额；朋友用其密码进入后只能看到自己的画廊与预设。
5. 如需对外提供 API，在「API 密钥」中签发密钥，按需设置模式、模型白名单、每日额度与并发上限。
6. 在「签到设置」中配置时刻表，工作台会按计划自动为账号池领取每日额度。

## 安全与隐私

- 所有密钥、密码、会话密钥均通过部署环境的密钥管理写入，不落仓库。
- 对外密钥与分享密码**只保存哈希**，不保存明文；账号凭据加密存储且绝不在接口中返回。
- 写操作带同源校验，会话为签名 Cookie；受保护页面默认需要登录。
- 日志不记录明文密钥与凭据。
